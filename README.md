# Missão ENEM · Matemática

Revisão gamificada de Matemática para o ENEM das turmas **M21 e M22** do Curso G9, com o Prof. Mateus Bibiano.

**Acesse:** https://mateusbibiano.github.io/missao-enem/

- 30 questões do ENEM em 4 fases: Porcentagem, Razão e Proporção, Estatística e Geometria Básica.
- Cada fase só é liberada quando todas as questões da fase anterior são acertadas.
- XP por dificuldade, sequência de acertos, níveis, estrelas, medalhas e certificado com código de verificação.
- Sem login: o progresso fica salvo no navegador de cada aluno.

O site é um único arquivo (`index.html`), sem dependências além das fontes do Google Fonts.
